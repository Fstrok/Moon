# Moon

Android-клиент для nude-moon.org: только функционал сайта в своём интерфейсе, вход по отпечатку.

## Установка

Готовый APK лежит в **Releases** (или в артефактах вкладки **Actions**: каждый push собирает `Moon-1.0.N.apk`).
Скачай на телефон, разреши установку из этого источника. Новые версии ставятся поверх старой: подпись одна и та же.

## Что умеет

| Сайт | В приложении |
|---|---|
| Каталог с сортировками | Каталог: Новое / Популярное / Лайки / Обсуждаемое / Объёмные, бесконечная прокрутка, pull-to-refresh |
| Разделы меню сайта | **Разделы подтягиваются с сайта сами.** Главная читается дважды — с входом и «как гость»: всё, что есть только у вошедшего, становится вкладкой каталога автоматически, при любой вёрстке. Остальные ссылки меню становятся вкладками, если открываются как список манги; любую можно закрепить вручную («Ещё → Разделы сайта»). Если страницу раздела не удаётся разобрать, она показывается как страница сайта, а тайтлы с неё открываются в приложении. Новые разделы помечены точкой |
| Закладки (избранное) сайта | **Двусторонняя синхронизация с избранным приложения**: закладки сайта приходят в приложение, ♥ в приложении ставит/снимает закладку на сайте (кнопку на странице тайтла нажимает невидимый встроенный браузер). Удаления переносятся по разнице с прошлой синхронизацией; пустой ответ сайта избранное не стирает. Изменения без сети/входа отправятся позже |
| Теги | Подбор по нескольким тегам сразу + сортировка, фильтр по названию, закрепление любимых тегов |
| Поиск (сайт: только после входа) | Поиск + история запросов + мгновенный поиск по избранному и истории без сети |
| Страница тайтла | Обложка, автор и переводчик (ведут на их списки), теги, описание, все главы, отметка прочитанного |
| Читалка | Лента (вебтун) или постранично (→/←), зум щипком и двойным тапом, зоны нажатия, листание громкостью, слайдер страниц, переход к следующей главе, предзагрузка, экран не гаснет |
| Вход | Свой экран входа; отпечатком открывается приложение и тут же выполняется вход на сайт, если сессия истекла |
| — | Избранное (сортировка, фильтр), история с прогрессом, «Продолжить» |
| — | Загрузки глав для офлайна (в приватную папку, в галерею не попадают) |
| Комментарии, лайки, профиль | Кнопка «на сайте» открывает страницу во встроенном браузере с той же сессией |

## Если что-то не нашлось

«Ещё → Диагностика сайта» собирает отчёт: что приложение видит в меню (как вошедший и как гость), какие разделы нашло,
где закладки и какие кнопки закладок на странице тайтла. Паролей и значений cookies в отчёте нет.
Кнопка «Поделиться» — отправить отчёт разработчику, чтобы поправить разбор под вёрстку сайта.

## Безопасность

- **Блокировка отпечатком** при запуске и после ухода в фон (задержка настраивается), запасной вариант — PIN телефона.
- **Пароль от сайта** хранится зашифрованным ключом Android Keystore, который открывается только отпечатком
  (`BIOMETRIC_STRONG`) и сбрасывается, если в телефон добавили новый отпечаток.
- По умолчанию **скрывается в списке недавних** и запрещает скриншоты (`FLAG_SECURE`), отключается в настройках.
- Бэкап данных приложения в облако выключен.

## Как работает вход

1. «Ещё → Войти»: логин и пароль вводятся в приложении. Невидимый WebView открывает сайт, сам заполняет его форму
   и отправляет её, поэтому вход работает при любой разметке формы.
2. Если сайт требует капчу или проверку Cloudflare — «Войти через сайт»: обычная страница сайта,
   приложение перехватывает введённые данные и предлагает сохранить их под отпечаток.
3. Сессия (cookie) общая у приложения и встроенного браузера.

## Cloudflare

Если сайт показывает проверку «Just a moment…», приложение откроет её во встроенном браузере. Пройди проверку,
окно закроется само, и экран перезагрузится. Если сайт переехал на зеркало — «Настройки → Сайт → Адрес».

## Сборка

```bash
./gradlew :app:testDebugUnitTest   # парсер + UI-тесты на Robolectric с макетом сайта
./gradlew :app:assembleRelease     # app/build/outputs/apk/release/app-release.apk
```

Стек: Kotlin, Jetpack Compose (Material 3), OkHttp, Jsoup, Coil 3, Telephoto, kotlinx.serialization, androidx.biometric.

Разбор HTML (`NudeMoonParser`) основан на селекторах открытого парсера Nude-Moon из Mihon/Tachiyomi
с запасными вариантами. Если сайт поменяет вёрстку, править нужно этот файл.

Ключ подписи `keystore/moon.jks` лежит в репозитории, чтобы сборки из CI ставились поверх друг друга.
